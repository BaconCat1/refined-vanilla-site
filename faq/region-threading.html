EU, NA and region threading

Two regional worlds, one community. Geographic regions and server tick regions are different things.

Which server should I join?

EU is the persistent main world, running 26.2 and accepting 26.3 Java clients. NA is a separate 26.3 test world. Pick a region using the join guide. NA may offer a shorter network route for North American players; latency depends on your connection.

What is shared?

Community chat, ranks and social features connect the regions. Worlds, inventories, items and XP stay separate. The [EU] and [NA] labels show the world someone is playing in. Use /rvservers for information and /na or /eu to switch.

What software runs RV?

RV currently uses custom Canvas-based server software, with Paper/Folia lineage. Older Fabric and Ruthenium descriptions refer to a previous setup.

What does region threading mean?

Within each server, nearby activity is grouped into tick regions. Independent regions can run in parallel while ownership rules control access to world state. This is unrelated to choosing Europe or North America and does not make those servers share a world.

Are all vanilla mechanics identical?

Preserving vanilla gameplay is a goal, not a guarantee for every contraption. Region boundaries, configuration and plugins can affect behavior. Report a reproducible example in Discord rather than relying on an older blanket compatibility claim.

Do regional rules differ?

EU permits Nether roof access; NA restricts roof access and new building. NA is currently used for version testing. Read current announcements before making assumptions about test-world status.
