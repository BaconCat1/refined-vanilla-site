About Us

Pure Vanilla, Done Right

RefinedVanilla is a no-hacks semi-anarchy community running custom Canvas-based server software. No client-side mods are required.

The persistent EU world currently runs 26.2. A separate NA test world runs 26.3. Java and Bedrock players can play together within a region. Worlds and player inventories remain separate.

Our server changes aim to preserve vanilla gameplay while supporting region threading and correcting bugs. Compatibility is tested, not assumed: report broken mechanics with a reproducible example.

Explore our server rules, join RefinedVanilla today, or connect with the community on Discord. Learn more about what vanilla anarchy means.
